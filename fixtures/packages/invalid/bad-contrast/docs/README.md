# matchday-neutral

Fictional neutral theme package for Open Matchday graphics tokens.

## Contents

Declarative only: colors, typography, logo slots, tokens, motion intensity, font license registry.

## Fonts

Uses the CSS generic family `sans-serif` ([CSS Fonts Module Level 4](https://www.w3.org/TR/css-fonts-4/#generic-font-families)). No font files are shipped in this package.

## Contrast

Pairs validated against [WCAG 2.2 Success Criterion 1.4.3 Contrast (Minimum)](https://www.w3.org/TR/WCAG22/#contrast-minimum) Level AA (4.5:1 for normal text).
